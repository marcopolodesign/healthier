3 RCTA — Solución para Recetas Electrónicas

Qué es

Plataforma de prescripción electrónica operada por Innovamed. Registrada en el Registro Nacional de Plataformas Digitales de Salud (MSAL). Cumple Ley 27.553.

Cobertura

Conecta con Farmalink — red que incluye OSDE, Swiss Medical, PAMI y ~2.000 obras sociales. QR + barcode por receta.

API disponible

QBI2 API — diseñada específicamente para integrar recetas electrónicas en sistemas de HC. Contacto: innovamed.com.ar/rcta-institucional

Costo

~$50.000 ARS/mes por médico para integración institucional vía API (confirmar con Innovamed). Free para uso individual del médico en la app.

💊
Decisión Integrar RCTA vía QBI2 API para toda la verticalidad de prescripciones. No construir sistema de recetas propio — es una obligación legal con validación externa, no un feature.

5 Próximos Pasos — Prioridad

  1. Registro AAIP — RNBD
    Registrar la base de datos de Healthier en el Registro Nacional de Bases de Datos de la AAIP. Obligatorio para cualquier app que almacene datos sensibles de salud. Trámite administrativo, 1–2 semanas. Independiente del stack técnico — hacerlo ya.
    Bloqueante para producción real aaip.gob.ar
  2. Rediseño del schema clínico en Supabase
    Crear tablas encounters, encounter_entries (append-only via trigger), conditions, allergies, medications con RLS completo, audit log de accesos y campos de matrícula profesional. Reemplaza el schema de Heural. Descarta OpenEMR.
    3–4 días Migrations + services
  3. Contactar Innovamed para QBI2 API (RCTA)
    Solicitar acceso a la QBI2 API para integración institucional de recetas electrónicas. Confirmar pricing por médico. URL: innovamed.com.ar/rcta-institucional. Necesario para cualquier profesional que emita recetas en la plataforma.
    Requerido para recetas Ley 27.553
  4. HC descargable en PDF por paciente
    Endpoint que genera PDF de historia clínica del paciente bajo demanda. Cumple Art. 15 Ley 26.529 (paciente recibe copia en 48hs). Solución MVP antes de tener interfaz completa de visualización.
    2 días Ley 26.529 Art. 15
  5. Actualizar T&C con lenguaje de equipo tratante
    Los términos y condiciones deben explicitar que profesionales que atiendan al mismo paciente pueden acceder a la historia clínica compartida. La pantalla de consentimiento (v2.1) ya cubre esto en la app mobile — hay que reflejarlo en los T&C formales.
    Legal Ley 25.326 Art. 11
  6. Monitorear Decreto 393/2023 — Sistema HCE unificado
    El registro nacional de HCE está en construcción. Nadie está formalmente certificado todavía. Cuando MSAL finalice los procedimientos operativos, evaluar registro. Por ahora: diseñar el schema con FHIR en mente (facilita migración futura).
    Largo plazo No bloqueante

Resumen Ejecutivo

Backend Clínico

Schema propio en Supabase. OpenEMR descartado — overkill, sin ventaja legal, servidor PHP adicional innecesario.

Recetas

RCTA via QBI2 API (Innovamed). Legalmente registrado, cubre todas las obras sociales. No construir propio.

Seguridad

Supabase ya cumple. AES-256 + TLS + RLS satisfacen Ley 25.326 Art. 9. No se necesita cifrado adicional.

Acción inmediata

Registro AAIP (RNBD). Independiente del stack. Bloqueante para tener pacientes reales en el sistema.
