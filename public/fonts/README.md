# Licensed Fonts

Drop the following `.woff2` files into this directory to activate the full design system typography. The site renders with high-quality free fallbacks (Fraunces → GT Super Display, Inter → Everett) until these files are present.

## GT Super Display

| File | Weight | Style |
|------|--------|-------|
| `GTSuperDisplay-Regular.woff2` | 400 | normal |
| `GTSuperDisplay-RegularItalic.woff2` | 400 | italic |
| `GTSuperDisplay-Medium.woff2` | 500 | normal |
| `GTSuperDisplay-Bold.woff2` | 700 | normal |

## Everett

| File | Weight | Style |
|------|--------|-------|
| `Everett-Regular.woff2` | 400 | normal |
| `Everett-Medium.woff2` | 500 | normal |
| `Everett-Bold.woff2` | 700 | normal |

Both typefaces are licensed from [Klim Type Foundry](https://klim.co.nz). Ensure you have the appropriate license before deploying to production.
