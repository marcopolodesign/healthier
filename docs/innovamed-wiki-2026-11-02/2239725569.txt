 Versión de documentación: v1.0

 Este Endpoint requiere Autenticación , por lo que se debe enviar un token válido en los Headers para autorizar las solicitudes.
 Este Endpoint página las respuestas para poder ser eficiente en las búsquedas, la cantidad de resultados por página (20) no es modificable.
 Descripción
 Este servicio se utiliza para obtener el listado de prácticas desde la base de datos que pueden ser utilizadas para prescribir, pudiendo aplicarse filtros para reducir la búsqueda o para obtener el listado completo.
 El servicio responde con el maestro de prácticas disponibles en Recipe agrupando cada una con sus datos, y ordenándolos por el ID de manera ascendente.

 Notas Técnicas
 Si no se ingresa ningún parámetro de búsqueda, el endpoint devolverá el listado completo de prácticas que estén habilitadas.
 Si se utiliza alguno de los filtros (nombre, tipo, categoría) y en la búsqueda no se encuentra coincidencia, el endpoint devolverá una lista vacía.
 Los filtros aceptan caracteres alfanuméricos y no distinguen entre mayúsculas y minúsculas ni palabras con tilde o sin tilde.
 Si al utilizar el filtro por nombre, se ingresan menos de 2 caracteres, el endpoint devolverá una lista vacía y No un error.
 Si se ingresa un espacio adelante en alguno de los parámetros de filtrado, el sistema realizará un trim para evitar que la búsqueda sea incorrecta.
 Si no se ingresa un número de página específico, el endpoint devolverá el total de prácticas, comenzando por la primer página.
 Las prácticas que se listen se ordenarán por su número de ID de manera ascendente.
 Las prácticas que se devuelvan en el listado serán aquellas habilitadas a listarse (que no estén “eliminadas en la DB).
