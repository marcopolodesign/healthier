 Versión de documentación: v1.0

 Este Endpoint requiere Autenticación , por lo que se debe enviar un token válido en los Headers para autorizar las solicitudes.
 Este Endpoint página las respuestas para poder ser eficiente en las búsquedas, la cantidad de resultados por página (20) no es modificable.
 Descripción
 Este Endpoint permite buscar medicamentos disponibles en la base de datos del sistema que utiliza el catálogo completo de Alfabeta, en todas las respuestas se ofrecen detalles si son:
 Psicofármaco
 Estupefaciente
 Venta controlada 
 HIV
 Requiere duplicado
 Ademas, en caso de proveer los datos de financiador y/o afiliado en la respuesta, se puede observar el cambio de estado en el campo “tieneCobertura” que por defecto es siempre “false”.

 Notas Técnicas
 Para realizar la búsqueda específica de algún producto, en el parámetro de búsqueda, se deben ingresar al menos 2 caracteres.
 Si no se especifica un parámetro opcional, se retornan resultados generales.
 La paginación se controla con el parámetro numeroPagina .
 El parámetro requiereDuplicado y hiv tienen afectación directa en la receta.
 Si se requiere duplicado, en la receta se generará una hoja más indicando que es el duplicado de la misma.
 Si se prescribe un medicamento HIV, los datos del paciente en la receta y el medicamento que se envía, estarán encriptados.
 A nivel cliente (clienteApp) existe una configuración disponible que se utiliza para codificar el número de producto (regNo) cuando son sensibles, por ejemplo, medicamentos HIV.
