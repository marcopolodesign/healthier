# Buscador de Financiadores (v5, 2026-03-31)
 ‌
 Versión de documentación: v2.0
 Fecha de modificación: 03/06/2025
 Este Endpoint requiere Autenticación , por lo que se debe enviar un token válido en los Headers para autorizar las solicitudes.
 Descripción
 Este Endpoint permite buscar los financiadores existentes en la base de datos del sistema.
 El servicio responde con el maestro de financiadores disponibles en Recipe agrupando cada uno con sus datos, y ordenándolos por el ID de manera ascendente.
 ID
 Número
 Nombre
 Además, para los casos donde se aplique y sea requerido, se visualizarán los planes que el financiador tenga asociados.
 Documentación Técnica
 URL
 GET {{baseUrl}}/apirecipe/GetFinanciadores
 Parámetros
 Este Endpoint no requiere el envío de parámetros.
 Ejemplo de solicitud
 curl -X GET "<base_URL>/apirecipe/GetFinanciadores" \
-H "Accept: application/json" \
-H "Authorization: Bearer <tu_token_de_acceso>"

 Notas Técnicas
 Actualmente el Endpoint lista la totalidad de los resultados sin paginación ni filtro de búsqueda.
 Los planes sólo se mostrarán para aquellos financiadores que requieran informar ese dato. Caso contrario, se visualizará el objeto vacío y no tiene ninguna afectación.
