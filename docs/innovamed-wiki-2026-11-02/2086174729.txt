# Buscador de Diagnósticos (v4, 2026-03-31)
 ‌
 Versión de documentación: v1.0
 Fecha de modificación: 02/01/2025
 Este Endpoint requiere Autenticación , por lo que se debe enviar un token válido en los Headers para autorizar las solicitudes.
 Descripción
 Este Endpoint se utiliza para obtener el listado de diagnósticos CIE-10. Para ello se debe realizar una búsqueda a partir de una cadena de texto, que al ejecutarse, devolverá los diagnósticos que coincidan con la búsqueda, tanto en el código como en la descripción.
 Documentación Técnica
 URL
 GET {{baseUrl}}/apirecipe/GetDiagnostico?text=A01
 Parámetros
 Los parámetros serán requeridos como URL params.
 Obligatorios
 Parámetro 
 Tipo 
 Descripción 
 Ejemplo 
 clienteAppId 
 Int
 ID correspondiente al cliente.
 123
 text 
 String
 Texto para filtrar resultados. Mínimo 3 caracteres, puede ser código ó descripción del diagnóstico.
 A010 ó FIEBRE 
 Ejemplo de solicitud
 curl -X GET "<base_URL>/apirecipe/GetDiagnostico?text=fiebre" \
-H "Accept: application/json" \
-H "Authorization: Bearer <tu_token_de_acceso>"

 Errores y Posibles Causas
 Código 
 Mensaje 
 Código HTTP 
 Causa 
 QBI136
 DEBE INGRESAR AL MENOS 3 CARACTERES
 400
 Se ingresaron menos de 3 caracteres en el texto de búsqueda.
 QBI181
 DIAGNÓSTICO SIN CÓDIGO ASOCIADO
 200
 El texto ingresado no coincide con ningún código de diagnóstico ni descripción. El servicio responde con código 200 y la lista de diagnósticos vacía.
 Notas Técnicas
 Para realizar la búsqueda específica de algún diagnóstico, en el parámetro de búsqueda, se deben ingresar al menos 3 caracteres.
 Si no se especifica ningún texto de búsqueda, el servicio responderá con un error.
