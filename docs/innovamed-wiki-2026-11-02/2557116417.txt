 Este Endpoint requiere Autenticación , por lo que se debe enviar un token válido en los Headers para autorizar las solicitudes.
 Descripción
 Este servicio se utiliza para anular una prescripción de prácticas utilizando el código HASH de la misma.
 Documentación Técnica
 URL 
 DELETE {{baseUrl}}/apirecipe/Practica/{id}
 Parámetros
 Los parámetros serán requeridos como URL params:
 Obligatorios
 Parámetro 
 Tipo 
 Descripción 
 Ejemplo 
 id 
 String
 HASH identificador de la prescripción. Este se puede visualizar en el response al momento de prescribir. No es el número de la prescripción.
 A0MIYNR5XP2OH8HWGFQP7BG 
 El siguiente parámetro deberá indicarse en el body:
 Parámetro 
 Tipo 
 Descripción 
 Ejemplo 
 clienteAppId 
 Int
 ID correspondiente al cliente. Este parámetro se debe indicar como parámetro del Body.
 123
 Ejemplo de solicitud
 curl --location --request DELETE '<base_URL>/apirecipe/Practica/O8IRHZ8JHHNZU2JMGJ585K3N3BPD9H1' \
--header 'Authorization: Bearer <tu_token_de_acceso> \
--header 'Content-Type: application/json' \
--data '{
 "clienteAppId": 142
}'
 Respuesta
 Todas las respuestas serán en formato JSON
 Exitosa
 Código de estado
 200 OK 
 Cuerpo de respuesta:
 {
 "codigoRespuesta": 0,
 "mensaje": "PRESCRIPCIÓN ANULADA CORRECTAMENTE"
}
 Fallida
 Código de estado
 400 Bad Request 
 Cuerpo de respuesta
 {
 "error": "QBI2 OPERACION INVALIDA.",
 "mensaje": "LA PRESCRIPCIÓN YA HABIA SIDO PREVIAMENTE ANULADA"
}
 {
 "error": "QBI2 OPERACION INVALIDA.",
 "mensaje": "NO SE ENCONTRÓ LA PRÁCTICA"
}
 Errores y Posibles Causas
 Código 
 Mensaje 
 Código HTTP 
 Causa 
 QBI79 
 LA RECETA HA VENCIDO EL DIA
 400
 La prescripción que se desea anular está vencida. 
 QBI2 
 QBI2 OPERACION INVALIDA.
 400
 La prescripción ya había sido previamente anulada / No se pudo obtener información de la prescripción que se precisa anular.
 QBI106 
 ERROR AL GENERAR EL TOKEN
 400
 Ocurre cuando se intenta generar un token para llamar a una API de mandataria y ésta falla.
 Notas Técnicas
 No se pueden anular recetas que ya fueron anuladas previamente.
